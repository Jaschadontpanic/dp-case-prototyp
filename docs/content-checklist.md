# dp-case.de – Content-Checkliste pro Seite

Diese Liste wird bei JEDER Seite (Produkt, Material, Standards etc.) vor "fertig" durchgegangen.

## Pflichtpunkte pro Seite
- [ ] Title-Tag (getrennt von H1, keyword-optimiert)
- [ ] H1
- [ ] Meta Description (150-160 Zeichen)
- [ ] Story/Intro-Text
- [ ] Breadcrumb sichtbar + Schema.org BreadcrumbList (mit echter URL, volle Navigationstiefe)
- [ ] Schema.org Hauptmarkup (Product ODER WebPage, je nach Seitentyp)
- [ ] Alt-Texte für alle Bilder
- [ ] Interne Links geprüft: zeigen sie auf existierende, aktuelle URLs?
- [ ] Synonym-/Suchbegriff-Check durchgeführt (inkl. Homonym-Gefahr wie "Ultraleicht")
- [ ] Trust-Zeile / Herkunfts-Hinweis wo passend
- [ ] CTA vorhanden

## Zusätzlich bei Produktseiten
- [ ] FAQ-Sektion + FAQPage-Schema.org
- [ ] Featured-Flag entschieden (ja/nein)
- [ ] Branchen-Tags (Achse B) festgelegt
- [ ] Gerätetyp-Zuordnung (Achse A) festgelegt, falls zutreffend
- [ ] Kundenreferenz-Position geklärt (nur wenn Freigabe vorliegt)

## Seitenbaum-Konvention (Stand aktuell)
- Materialien liegen unter /engineering/materialien/… (Entscheidung 2026-09-25, ersetzt die frühere Regel „kein /engineering/-Präfix“)
- Breadcrumbs zeigen volle Navigationstiefe (inkl. Engineering)
- Übersichtsseiten (beide Achsen) erst sichtbar ab 3+ passenden Unterseiten/Produkten;
  bei nur 1 fertiger Unterkategorie: NUR diese als Kachel zeigen, keine leeren Kacheln
