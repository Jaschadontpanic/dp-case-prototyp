# Anweisungen für Claude Code

Vor jeder Aufgabe lesen: `docs/code-rules.md`, `docs/design-system.md`, `docs/project-rules.md`. Bei Bedarf: `docs/seitenstruktur.md`, `docs/open-decisions.md`.

Kernregeln:
1. Texte aus `content/` nie eigenständig ändern, kürzen oder ergänzen. Bei Bedarf nachfragen.
2. Nur relative Links (Vorschau liegt unter `/dp-case-prototyp/`).
3. Keine neuen Design-Werte erfinden; nur Variablen aus `assets/css/tokens.css`.
4. Keine Frameworks, kein Build-System.
5. Jede Seite: `<meta name="robots" content="noindex, nofollow">`.
6. Nur relevante Dateien lesen (Token-Effizienz). Nach Änderungen Desktop/Tablet/Mobile, Links und Bilder prüfen und kurz zusammenfassen.
7. Entscheidungen mit Auswirkung auf Content, Designkonzept oder Struktur: Optionen + Empfehlung nennen und auf Freigabe warten.
